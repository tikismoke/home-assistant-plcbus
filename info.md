# PLCBus

Home Assistant switch control for a PLCBUS serial adapter.

Install this custom integration through HACS and restart Home Assistant. Then
open **Settings > Devices & services > Add integration > PLCBus** to configure
the serial device, user code, and optional units.

Settings can be changed with **Reconfigure**. Legacy YAML configuration is
imported once; remove it after the integration appears in Devices & services.

See [README.md](README.md) for installation, migration, and limitations.
